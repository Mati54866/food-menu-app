# Contributing to Food Menu App 🥡

Thank you for your interest in contributing to **Food Menu App**!

---

## 🛠️ Local Development Setup

1. **Fork & Clone**
   ```bash
   git clone https://github.com/YOUR_USERNAME/food-menu-app.git
   cd food-menu-app
   ```

2. **Install All Dependencies**
   ```bash
   npm run install:all
   ```

3. **Start Backend & Frontend Services**
   - Backend: `npm run dev:backend`
   - Frontend: `npm run dev:frontend`
